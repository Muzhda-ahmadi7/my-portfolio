A front-end project focused on creating a clean and responsive contact form using HTML and CSS. The project was developed to practice structured HTML, CSS styling, responsive layouts, and form design across different screen sizes.

Description

This project focuses on building a functional-looking contact form interface from the ground up. The main emphasis was on creating a clear HTML structure and using CSS to develop the visual design while ensuring that the layout adapts to different screen sizes.

Project Goal

The main goal was to strengthen my understanding of HTML and CSS while learning how to create responsive interfaces. The project also provided practical experience designing and organizing form fields in a clear and user-friendly layout.

Technologies

HTML CSS GitHub

My Role

I was responsible for building the HTML structure and implementing the CSS styling and responsive behavior of the interface. I focused on creating a clean layout, organizing the form elements, and adapting the design for different screen sizes.

Responsive Design

The project was designed to adapt to different screen sizes using responsive CSS techniques and media queries. The layout was adjusted to remain clear and usable across desktop, tablet, and mobile screen widths.
