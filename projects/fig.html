Personal Portfolio Website

A personal portfolio website concept designed in Figma to create a clean, refined, and distinctive digital presence for a front-end developer. The design focuses on clear typography, thoughtful spacing, visual hierarchy, and a minimal interface.

Description

This project explores the visual design of a personal portfolio for a front-end developer. The goal was to create an interface that feels clean, intentional, and professional while allowing the projects and work to remain the main focus.

Goal

The goal was to design a portfolio that communicates both technical ability and visual thinking without relying on a generic portfolio template. The interface uses a restrained layout, strong typography, generous whitespace, and subtle visual accents to create a distinctive identity.
